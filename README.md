# Туҳр

Ҳанафий мазҳаби бўйича ҳайз, нифос ва истеҳоза ҳукмларини ўрганиш ва ҳисоблаш учун дастур. Ҳисоблар Имом Биркивийнинг ҳайз рисоласи ва Ибн Обидин шарҳидаги қоидалар асосида. Бу шахсий фатво эмас.

**Юклаб олиш:** ўнг томондаги **Releases** бўлимидан энг сўнгги `tuhr-1.0.N.apk` файлини олинг. Янги версия эскисининг устидан ўрнатилади ва маълумотлар сақланиб қолади.

---

## Махфийлик сиёсати

*Охирги таҳрир: 2026 йил 21 сентябрь*

«Туҳр» дастури (кейинги ўринларда — дастур) фойдаланувчи ҳақида ҳеч қандай маълумот тўпламайди, сақламайди ва ҳеч кимга юбормайди.

1. **Маълумотлар фақат телефонингизда сақланади.** Исм, ёш, одат, тақвим ёзувлари, тест жавоблари ва созламалар фақат шу қурилманинг ичида сақланади. Улар бирорта серверга, дастур муаллифига ёки учинчи томонга юборилмайди.
2. **Рўйхатдан ўтиш ихтиёрий ва маҳаллий.** «Рўйхатдан ўтиш» фақат шу телефонда профил яратади. Ҳисоб қайдномаси (аккаунт), электрон почта ёки телефон рақами сўралмайди.
3. **Интернет фақат иккита ҳолатда ишлатилади:** янги версия чиққан-чиқмаганини билиш учун дастур GitHub'даги очиқ «Releases» саҳифасига мурожаат қилади, «Савол» бўлими эса (фақат веб-версияда) фойдаланувчи ўзи ёзган саволни жавоб олиш учун юборади. Бу мурожаатларга шахсий маълумот қўшилмайди.
4. **Эслатмалар** ихтиёрий бўлиб, фақат фойдаланувчи ёқса ишлайди. Улар телефоннинг ўзида режалаштирилади ва интернет талаб қилмайди.
5. **Захира нусха** файлини фақат фойдаланувчининг ўзи яратади ва уни қаерга сақлашни ўзи танлайди.
6. **PIN-код** телефонда шифрланган (хеш) кўринишда сақланади ва ҳеч қаерга юборилмайди.
7. **Реклама ва кузатув йўқ.** Дастурда реклама, таҳлил (analytics) ёки кузатувчи кодлар йўқ.
8. **Маълумотларни ўчириш.** Дастурни ўчириб ташлаш ёки «Тақвимим» созламаларидаги «Барчасини ўчириш» тугмаси барча маълумотларни бутунлай йўқ қилади.

Саволлар бўйича: GitHub'даги ушбу омборнинг **Issues** бўлими орқали мурожаат қилишингиз мумкин.
